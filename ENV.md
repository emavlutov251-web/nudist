# Переменные окружения «Нудиста»

Все настройки сервера. Обязательных нет: без единой переменной сервер запускается на `http://localhost:3000` с базой в папке `data/`.
На своём сервере переменные лежат в `/etc/nudist.env` (после правки — `sudo systemctl restart nudist`), в Docker — в `.env`.
Список сверяется с кодом автоматически: `node scripts/check-project.js` (идёт в `npm test` и в GitHub Actions) падает, если в коде появилась переменная, которой здесь нет.

## Основное

| Переменная | По умолчанию | Что делает |
|---|---|---|
| `PORT` | `3000` | Порт сервера. |
| `HOST` | `0.0.0.0` | На каком адресе слушать. За Caddy — `127.0.0.1`. |
| `DATA_DIR` | `./data` | Где лежит база (`db.json`), её копия и загруженные файлы. |
| `NODE_ENV` | — | `production` — рабочий сервер: первая регистрация только с кодом установки, проверочные переменные не действуют. |
| `SITE_URL` | — | Публичный адрес сайта (`https://…`). Нужен для оплаты, входа через Telegram, ссылок в письмах бота. |
| `SETUP_CODE` | создаётся сам | Код установки для первой регистрации на рабочем сервере (от 8 символов). `off` — не спрашивать. |
| `OWNERS` | — | id аккаунтов-владельцев через запятую: всегда главные админы, ими нельзя управлять из админки. |
| `LEAF_ADMINS` | владельцы | id аккаунтов, которым разрешено выдавать листики и подписку из админки. |
| `IMPORTERS` | — | id аккаунтов без лимитов на загрузку (перенос из Telegram, редакция). |
| `ROBOTS` | — | id служебных аккаунтов: от них идут подборки и автопостинг, в рейтингах не участвуют. |
| `TRUST_PROXY` | авто | Верить ли заголовку `X-Forwarded-For`: `on`, `off` или авто (верим, если запрос пришёл с внутреннего адреса). |
| `MAINT` | — | Разовая работа по базе при запуске: `<метка>:<действие>,…` (`unmute`, `stars=N`, `staffstars=N`, `resetlink=<id>`). Каждая метка выполняется один раз. |
| `KEEP_AWAKE` | авто | Будить самого себя на хостингах, которые усыпляют сервис: `always`, `off` или авто (кроме ночи по Москве). |
| `KEEP_AWAKE_URL` | адрес сервиса | Какой адрес будить. |
| `RENDER`, `RENDER_EXTERNAL_URL` | — | Выставляет сам Render: признак хостинга и его адрес (берётся, если не задан `SITE_URL`). |

## Переезд и мост к Telegram

| Переменная | Что делает |
|---|---|
| `MOVED_TO` | Сервис переехал: вместо приложения запускается заглушка, которая переносит людей на этот адрес (`server/moved.js`). Базу не открывает. |
| `RELAY_KEY` | Общий ключ моста к Telegram в заглушке переезда. Без него мост закрыт. |
| `TG_API` | Адрес Bot API. По умолчанию `https://api.telegram.org`; если Telegram с сервера недоступен — адрес моста. |
| `TG_HOOK_URL` | Куда Telegram шлёт сообщения боту, если не на сам сайт (адрес моста). |

## Telegram

| Переменная | По умолчанию | Что делает |
|---|---|---|
| `TG_BOT_TOKEN` | — | Ключ бота от @BotFather: вход через Telegram и импорт стикеров. |
| `TG_LOGIN` | включён | `off` — выключить вход через Telegram. |
| `TG_SETUP_MS` | `2500` | Через сколько миллисекунд после запуска настраивать бота. Для проверок. |

## Хранилище и копии базы

| Переменная | По умолчанию | Что делает |
|---|---|---|
| `SUPABASE_URL`, `SUPABASE_KEY` | — | Снимок базы в Supabase (ключ `service_role`). На хостинге без диска — основное хранилище, на своём сервере — запасная копия. |
| `SUPABASE_ROW` | `main` | Имя строки со снимком (для второго, проверочного сервера на той же таблице). |
| `SUPABASE_BUCKET` | `nudist` | Бакет Supabase Storage для файлов, если нет S3. |
| `S3_ENDPOINT`, `S3_REGION`, `S3_BUCKET`, `S3_KEY_ID`, `S3_SECRET` | — | S3-совместимое хранилище для файлов пользователей и ежедневных копий базы. |
| `S3_PREFIX` | `uploads` | Папка для файлов в бакете. |
| `S3_MAX_GB` | `14` | Свой потолок объёма: сверх него загрузка отклоняется (у Cloud.ru бесплатно 15 ГБ). |
| `DB_MIRROR` | включено при S3 | `off` — не класть копии базы в S3. |
| `CACHE_MB` | `700` | Сколько мегабайт файлов держать на диске сервера как кеш (остальное — в S3). |
| `FILE_DELAY_MS` | `60000` | Через сколько миллисекунд файл удалённого сообщения стирается из хранилища. |

## Загрузки и лимиты

| Переменная | По умолчанию | Что делает |
|---|---|---|
| `MAX_UPLOAD_MB` | 100 (400 с подпиской) | Предел одного файла. |
| `UPLOADS_PER_HOUR` | `200` | Файлов в час с одного аккаунта. |
| `MSG_LEAF_PRICE` | `25` | Сколько листиков берётся с незнакомца за первое сообщение в личку, если получатель выбрал «Сообщения за листики». Листики достаются получателю. |
| `FCM_SERVICE_ACCOUNT` | — | Сервисный аккаунт Firebase для push в Android-приложение (FCM HTTP v1): всё JSON одной строкой, либо путь к файлу. Не задан — push в Android идёт через ленту (`/api/notify`, приложение опрашивает её само). iOS не поддерживается. |
| `UPLOAD_MB_PER_HOUR` | `1024` | Мегабайт в час с одного аккаунта. |
| `MUSIC_MAX_TRACKS` | `300` | Треков в одной библиотеке. |
| `LIVE_MAX_VIEWERS` | `30` | Зрителей в одном эфире. |
| `RSS_KEEP` | `400` | Сколько записей ленты помнить, чтобы не публиковать повторно. |
| `RSS_MAX_TEXT` | `30000` | Предел длины статьи при автопостинге. |

## Уведомления

| Переменная | По умолчанию | Что делает |
|---|---|---|
| `VAPID_PUBLIC`, `VAPID_PRIVATE` | создаются сами | Ключи веб-уведомлений. Если не заданы, сервер создаёт их и хранит в базе. |
| `VAPID_SUBJECT` | `mailto:admin@nudist.app` | Контакт владельца для служб уведомлений браузеров. |
| `DIGEST_HOUR` | `13` | Час по Москве для сводки тем, кто давно не заходил. `off` — не слать. |
| `COMMUNITY_AUTO` | — | «Редакция сообщества»: тихие ежедневные посты в «Сообщество Нудист» (вопрос дня 09:00, мем-батл по пятницам, адвент в декабре, итоги недели в воскресенье, анонсы стартов событий). `off` — выключить. |
| `COMMUNITY_CHAT` | `auto` | Куда пишет «Редакция»: `auto` — в «Весь Нудист» (там все), иначе в «Сообщество Нудист»; `common` — только в общую беседу; `community` — только в клуб; `both` — в обе. |
| `STREAK_REMIND_HOUR` | `19` | Час по Москве для напоминания о серии переписки. |
| `REMIND_AFTER_S` | `90` | Через сколько секунд после запуска проверить напоминания о подписке. |

## Только для проверок

На рабочем сервере не задавать. `EVENTS_NOW` при `NODE_ENV=production` не действует вовсе.

| Переменная | Что делает |
|---|---|
| `EVENTS_NOW` | Сдвигает часы событий на указанную дату. |
| `ALLOW_PRIVATE_FETCH` | `1` — разрешить серверу ходить на внутренние адреса (превью ссылок в тестах). |
| `PUSH_ALLOW_ANY` | Принимать подписки на уведомления с любого адреса. |
| `BUILD_SALT` | «Выложить новую версию», не меняя файлов. |
| `NO_SW` | Отдавать офлайн-кеш, который стирает сам себя. |
| `CAPSULE_MIN_MS`, `CAPSULE_TICK_MS` | Минимальный срок капсулы и частота проверки. |
| `LOBBY_CAP_S`, `LOBBY_OFF_MS` | Предел раунда и срок «пропал из сети» в лобби. |
