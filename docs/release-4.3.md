# «Нудист» 4.3 — обновления в Telegram и просьба привязать Telegram

Выложено: прод `855d0da`, Android-сборка `code 43`, файл `/nudist.apk` (920 923 Б).
Страница скачивания: https://95-174-95-148.sslip.io/start

## Что появилось

### 1. Бот присылает новости об обновлениях

Раньше узнавать о новой сборке можно было только из ленты телефона и браузерных пушей.
Теперь бот **@nudist_gif_gif_bot** пишет в Telegram всем, кто его когда-то запускал:

* заголовок «Вышло обновление «Нудиста» 4.3»;
* список новинок — из `public/apk.json`;
* ссылка на страницу скачивания;
* строка «если бот не нужен — заблокируйте его».

Отправить: **Настройки → Админка → Объявления → «Разослать обновление»**.
Тот же путь работает из скрипта выкладки:

```
curl -X POST https://95-174-95-148.sslip.io/api/admin/news \
  -H "authorization: Bearer $NEWS_KEY" -H "content-type: application/json" -d '{}'
```

Правила тишины (не дают превратить бота в спам):

| Правило | Как сделано |
|---|---|
| Одному человеку — не чаще раза в день | отметки `meta.tgNewsSent` по каждому аккаунту |
| Не больше двух рассылок в сутки | счётчик `meta.tgNewsDay` по московским суткам |
| Ночью (23:00–9:00 МСК) не будим | поручение `meta.tgNewsDue`, служба сама отправит в 9:05 |
| Заблокировали бота | помечаем `tg.bad`, больше не стучимся |

Ограничение Telegram, которое не обойти: **бот не может написать первым** тому, кто ни разу
не нажимал «Start». Поэтому получатели — только привязавшие Telegram. Сейчас это 5 аккаунтов
из 38 — отсюда и вторая часть сборки.

Отправка идёт не напрямую: с сервера в России `api.telegram.org` недоступен (проверено —
соединение по IPv4 отваливается по таймауту). Работает через мост Supabase Edge Function
(`TG_API=…/tg/relay/<ключ>`), который уже был настроен для входа через Telegram.

### 2. Мягкая, но неотступная просьба привязать Telegram

* **Полоска над чатами** «Привяжите Telegram» — с объяснением, зачем это человеку:
  «это ключ на случай, если забудете пароль или смените телефон. Вход в один тап».
  Если пароля нет — «Пока не задан пароль, Telegram — единственный способ войти с другого устройства».
* **Первая подсказка** сверху с кнопкой «Привязать» — показывается после приветствия
  и напоминания про уведомления, никогда поверх открытых окон.
* **Крестик откладывает на 3 дня**, потом просьба возвращается. Привязал — исчезает сразу и навсегда.
* Ничего не блокируется: человек всегда может закрыть и пользоваться дальше.
* Работает одинаково на сайте и в приложении (APK).

## Попутные исправления

* `/api/tg/health` — простой адрес «жив ли сайт» для проверки перед скачиванием.
* Обычным HTTP-запросом больше нельзя удалить аккаунт (`me.delete`): запасной путь для
  онлайн-игр теперь открывает только чтение и настройки «про себя».
* Ключ рассылки живёт в настройках сервера (`NEWS_KEY`) и открывает **только** `/api/admin/news`:
  статистика, флаги и остальная админка им закрыты.
