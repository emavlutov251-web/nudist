Нудист

Мессенджер, которому нечего скрывать

Чаты, группы, звонки, лента и анонимные вопросы. Номер телефона не нужен: придумали имя и пароль — и вы внутри.

Приложение для Android

Файл APK, 25 КБ — легче любого мема. Ставится за минуту.

Приложение пока есть только для Android. На iPhone «Нудист» работает в Safari: открыть, затем «Поделиться» → «На экран „Домой“».
APK ставится на телефон с Android. Наведите камеру телефона на код — эта страница откроется на нём.
Скачать APK
Файл скачивается. Дальше так:
  1. Откройте nudist.apk из загрузок.
  2. Телефон спросит, можно ли ставить приложения из этого источника — разрешите.
  3. Нажмите «Установить». Приложения нет в Google Play, поэтому телефон может переспросить.
